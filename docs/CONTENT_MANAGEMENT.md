# Content Management Dashboard Guide

The Content Management Dashboard allows administrators to edit and manage all website content across different sections of the Seeds of Love Foundation website.

## Features

### 1. Content Overview
The dashboard displays statistics about your content:
- **Total Content**: Count of all content items in the system
- **Published**: Number of items currently live on the website
- **Drafts**: Items saved but not yet published
- **Sections**: Number of different content categories

### 2. Search & Filter
- **Search**: Find content by title or content text
- **Section Filter**: View content from specific pages (Home, About, Programs, Get Involved, Contact)
- **Status Filter**: Show only published or draft content
- **Sort Options**: Order content by last updated, created date, or alphabetically by title

### 3. Content Management Actions

#### Edit Content
1. Click the "Edit" button on any content item
2. The content text area becomes editable
3. Make your changes
4. Click "Save" to update (automatically publishes the content)
5. Click "Cancel" to discard changes

#### Publish/Unpublish
- **Publish**: Makes content visible on the live website
- **Unpublish**: Hides content from the website while keeping it in the system
- Use the "Publish" or "Unpublish" button to toggle status

#### Delete
- Click "Delete" to permanently remove a content item from the system
- This action cannot be undone, so use with caution

#### Add New Content
1. Click "+ Add New Content" button
2. A new draft item is created
3. Edit it by clicking "Edit" and filling in the content
4. Click "Save" to publish or leave as draft

## Content Sections Explained

### Home
Content that appears on the main landing page:
- **Hero Section**: Main headline
- **Hero Subtitle**: Subheading below hero
- **Primary CTA**: Call-to-action text

### About
Information about the foundation:
- **About Us**: Organization background
- **Mission Statement**: Core mission
- **Vision Statement**: Future vision

### Programs
Program-related content:
- **Programs Page Introduction**: Text at the top of the programs page

### Get Involved
Ways for people to participate:
- **Donation Page Intro**: Introduction to giving
- **Volunteer Information**: Volunteer opportunities

### Contact
Contact page content:
- **Contact Page Introduction**: Introductory text

## Best Practices

1. **Keep it Concise**: Write clear, compelling content without unnecessary words
2. **Use Descriptive Titles**: Make it easy to identify content items
3. **Review Before Publishing**: Always proofread before publishing changes
4. **Version History**: Note important changes - the system tracks last updated date
5. **Monitor Drafts**: Regularly check for draft items that may need publishing
6. **Consistency**: Maintain consistent tone and messaging across all sections

## Tips & Tricks

- Use the search bar to quickly find specific content
- Sort by "Last Updated" to see recently modified items
- Filter by section to focus on a specific part of the website
- The character count shows you how much content you've entered
- All changes are saved to the system, allowing you to edit existing content anytime

## Troubleshooting

**Content not appearing on the website:**
- Check that the item status is "Published" (not "Draft")
- Ensure the item is in the correct section
- Try clearing your browser cache and refreshing the page

**Lost unsaved changes:**
- Click "Cancel" if you want to discard edits
- Always click "Save" before leaving an edit mode
