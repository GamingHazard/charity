# Content Management Dashboard - Quick Start Guide

## Accessing the Dashboard

1. Log in to the dashboard with any email and a password (6+ characters)
2. Click on "Content" in the sidebar navigation (📝 icon)
3. You'll see the Content Management Dashboard

## Your First Actions

### View All Content
The dashboard opens showing all content items across the entire website. You'll see:
- **Statistics at the top**: Total items, published count, drafts, and sections
- **Filter controls**: Search, filter by section/status, and sort options
- **Content list**: All items displayed as cards

### Search for Specific Content
1. Type in the "Search Content" box to find content by title or text
2. Results update instantly as you type
3. Clear the search box to see all content again

### Filter by Section
1. Click the "Section" dropdown
2. Choose a specific page (Home, About, Programs, etc.)
3. Only content from that section will be displayed
4. Select "All" to see everything again

### Filter by Status
1. Click the "Status" dropdown
2. Choose "published" to see live content only
3. Choose "draft" to see unpublished items
4. Select "All" to see both

### Sort Content
1. Click the "Sort By" dropdown
2. Choose:
   - **Last Updated**: Most recently modified items first
   - **Created**: Newest items first
   - **Title (A-Z)**: Alphabetical order

## Editing Content

### To Edit Existing Content:
1. Find the content item you want to edit
2. Click the **"Edit"** button on that item
3. The content box becomes editable (white background)
4. Make your changes in the text area
5. You'll see the character count update
6. Click **"Save"** when done (automatically publishes)
7. Click **"Cancel"** if you want to discard changes

### To Add New Content:
1. Click the **"+ Add New Content"** button at the top
2. A new draft item appears at the bottom
3. Click **"Edit"** on the new item
4. Enter your content
5. Click **"Save"** to publish it
6. Or leave as draft and click **"Save"** with status as draft

## Publishing & Unpublishing

### Publish Content
- Click the **"Publish"** button on any draft item
- The item becomes live on the website
- Status badge changes from yellow (draft) to green (published)

### Unpublish Content
- Click the **"Unpublish"** button on any published item
- The item is hidden from the website
- Status badge changes from green to yellow
- Content remains in the system for later use

## Deleting Content

### Delete a Content Item:
1. Find the item you want to delete
2. Click the **"Delete"** button (appears in red)
3. The item is permanently removed
4. **Warning**: This cannot be undone!

## Understanding Content Sections

Each piece of content belongs to a page section:

| Section | Purpose | Examples |
|---------|---------|----------|
| **Home** | Main landing page | Hero headline, subtitle, call-to-action |
| **About** | About the foundation | Mission, vision, organization story |
| **Programs** | Programs page | Program descriptions and details |
| **Get Involved** | Ways to participate | Donation info, volunteer opportunities |
| **Contact** | Contact information | Contact page text |

## Tips for Success

✅ **Do's:**
- Keep content clear and concise
- Use descriptive titles so you can find items easily
- Review content before publishing
- Update content regularly
- Use the search to find specific items quickly

❌ **Don'ts:**
- Don't delete content unless you're sure
- Don't publish draft content without reviewing
- Don't leave important updates as drafts
- Avoid very long content blocks (use multiple items instead)

## Common Tasks

### I want to change the hero text
1. Search for "Hero"
2. Click Edit on "Hero Section"
3. Update the text
4. Click Save

### I want to update the mission statement
1. Filter by section: "About"
2. Find "Mission Statement"
3. Click Edit
4. Update text
5. Click Save

### I'm working on new content but not ready to publish
1. Create new content (+ Add New Content)
2. Write your content
3. Leave it as "Draft" (don't publish)
4. Come back later to finish and publish

### I want to see only what's currently live
1. Filter by section: "All"
2. Filter by status: "published"
3. Now you see only live website content

### I want to find all my recent changes
1. Sort by: "Last Updated"
2. Your most recent edits appear first

## Keyboard Shortcuts

- **Ctrl+Enter** or **Cmd+Enter**: Save (when editing in text area)
- **Escape**: Cancel editing
- **Ctrl+F** or **Cmd+F**: Search content
